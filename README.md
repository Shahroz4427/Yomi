# 🎌 Yomi — Anime Streaming App

**Yomi** is a Flutter-based anime streaming application designed for anime enthusiasts. It aims to provide a modern anime browsing and streaming experience with useful features such as built-in filler guides, automatic skip controls, and a seasonal anime calendar.

## ✨ Features

- 🏠 **Home Screen** — Discover trending, popular, top-rated, and currently airing anime.
- 🔍 **Search** — Search for anime and explore trending searches.
- 🎞️ **Anime Details** — Explore anime information, ratings, genres, and episode details.
- 📺 **Anime Streaming** — Watch your favorite anime in one place.
- ⏭️ **Auto Skip Controls** — Skip opening, ending, and filler episodes.
- 📖 **Filler Guides** — Identify canon, filler, and mixed episodes.
- 📅 **Seasonal Calendar** — Explore upcoming anime releases and seasonal schedules.
- 📱 **Responsive UI** — Designed to provide a smooth experience across different screen sizes.

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Programming Language:** Dart
- **UI:** Material Design
- **State Management:** Flutter's built-in state management (initial development)

## 🚀 Getting Started

Follow these steps to run Yomi locally.

### Prerequisites

- Flutter SDK installed
- Dart SDK
- Android Studio or VS Code
- An Android emulator or physical device

### Installation

**1. Clone the repository**

```bash
git clone <your-repository-url>
```

**2. Navigate to the project directory**

```bash
cd yomi
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```
